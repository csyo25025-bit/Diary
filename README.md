　　　関数はなぜ必要なのか？：同じことを繰り返し書くのが大変だから。

　　　引数：中に放り込む材料（攻撃力、守備力）

　　　処理：中で行われる計算（材料を混ぜる、１．５倍にするなど）

　　　戻り値：出てくるジュース（最終的なダメージ）

　　　役割ごとに関数を作って分担することをモジュール化という。

　　　プロトタイプ宣言：あらかじめコンピュータに「後でこういう関数が出てくるから覚えておいて」と予約しておくこと

　　　使わないとmain関数の上で書くとmain関数が埋もれてしまう。

　　　戻り値は「おつかいの結果」、引数は「おつかいのメモ」

　　　引数あり、戻り値なし：実行して終わり

　　　引数あり、戻り値あり：計算して結果を返す

　　　戻り値として返せる値は一つの関数につき一つまで。
